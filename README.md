# Advice

Pour que l'histoire soit compréhensible sans les images, je conserverais trois types de matériau :

① Répliques structurantes

Robin : « … »
Little John : « … »

② Bruitages immédiatement compréhensibles

Flèche → foule → porte → prison → feu → plongeon…

③ Quelques secondes de musique

Notamment le thème musical ou les passages très reconnaissables.

Cela permet de faire :

dialogue → ambiance → dialogue → musique → dialogue

plutôt qu'une succession parfois difficile à suivre de voix sorties de leur contexte.
